# Programming for Problem Solving - 1 (24CSEN1031)

**Category:** Faculty Core &middot; **Credits:** 3 &middot; **L-T-P-S-J:** 0-0-6-0-0

## 🧠 What this subject is about
This is where you learn to talk to a computer by writing code. You start with the basics: storing information in variables, making decisions with "if" statements, repeating actions with loops, and packaging steps into functions. The real skill you build is problem solving — breaking a big, scary task into small, simple steps a computer can follow.

## 🌍 Why it matters in the real world
Every app, website, and game began as someone writing simple instructions like these. Learning to break problems into steps is a superpower for any career, not just coding. And in AI and machine learning, programming is the tool you use to actually build and test your ideas — you cannot do ML without first being comfortable writing code.

## 🎯 A practical real-world problem to learn it
Build a "Guess the Number" game. The computer secretly picks a number between 1 and 100, and the player keeps guessing. After each guess, your program says "too high" or "too low" until the player gets it right, and then it tells them how many tries it took. This tiny game uses almost every beginner idea at once: variables to store the secret number, a loop to keep asking, "if" statements to compare, and functions to keep it tidy. It is fun, finishes in an afternoon, and you can show it off to friends.

## 🛠️ What you'd build or try
- Make the computer pick a random secret number.
- Use a loop to keep asking the player to guess.
- Add "if" checks to say "too high" or "too low."
- Count the guesses and print a friendly message when they win.

## 📚 Key ideas you'll practice
- Variables and storing data
- Conditionals (if / else decisions)
- Loops (repeating actions)
- Functions (reusable blocks of code)
- Breaking a problem into small steps
