# Programming for Problem Solving - 2 (24CSEN1041)

**Category:** Faculty Core &middot; **Credits:** 3 &middot; **L-T-P-S-J:** 0-0-6-0-0

## 🧠 What this subject is about
This is part two of learning to code, where you handle bigger and more interesting data. You learn to store many values at once in arrays, work with text using strings, group related information together with structures, and save your work to files so it does not disappear. You also learn to split a program into neat modules, like building with organized blocks.

## 🌍 Why it matters in the real world
Real programs deal with lots of data: a contact list, a game's high scores, a shop's inventory. The skills here — arrays, files, and organizing code — are exactly what you need to build useful tools. In AI and machine learning, you constantly load data from files, store it in arrays, and clean up text, so this subject is the bridge to real projects.

## 🎯 A practical real-world problem to learn it
Build a simple "Student Marks Manager." Your program lets you type in student names and their marks, stores them together, and then does helpful things: find the class average, spot the highest and lowest scorer, and sort everyone by rank. Best of all, it saves the data to a file, so when you close and reopen the program, your students are still there. This is a real tool a teacher could use, and it stretches every skill in this course — arrays to hold marks, strings for names, structures to bundle them, and files to remember everything.

## 🛠️ What you'd build or try
- Store many students' names and marks using arrays and structures.
- Calculate average, highest, and lowest marks.
- Sort students by rank from a small sorting routine.
- Save and load the data from a file so it stays between runs.

## 📚 Key ideas you'll practice
- Arrays (many values in one place)
- Strings (working with text)
- Structures (grouping related data)
- Reading and writing files
- Modular programming (organizing code into pieces)
