# Linear Algebra (MATH1272)

**Category:** Faculty Core &middot; **Credits:** 4 &middot; **L-T-P-S-J:** 3-1-0-0-0

## 🧠 What this subject is about
Linear algebra is the math of lists of numbers (called vectors) and grids of numbers (called matrices). It teaches you how to store lots of information neatly and then transform it — stretch it, rotate it, or combine it — using simple rules. It sounds abstract, but it is really about organizing data and moving it around.

## 🌍 Why it matters in the real world
Every image on your screen is a grid of numbers, so photo filters are just matrix math. Google Maps finds routes using linear algebra. Most importantly, it is the beating heart of AI and machine learning: neural networks are basically millions of vectors and matrices being multiplied together. If you understand linear algebra, you understand the engine inside modern AI.

## 🎯 A practical real-world problem to learn it
Build a tiny movie recommendation idea, like a baby version of what Netflix does. Imagine you have a few friends and a few movies, and each friend gives each movie a star rating. Put those ratings in a grid (a matrix). Now, can you figure out which two friends have the most similar taste? Or guess what rating a friend would give a movie they have not seen yet? This is a real problem that recommender systems solve, and the core trick is comparing vectors and doing matrix math. Start small with 4 friends and 5 movies, and grow from there.

## 🛠️ What you'd build or try
- Make a ratings grid (matrix) with friends as rows and movies as columns.
- Turn each friend's ratings into a vector and measure how "close" two vectors are.
- Use matrix operations to find the most similar friends.
- Try predicting a missing rating by combining similar friends' opinions.

## 📚 Key ideas you'll practice
- Vectors and what it means for two to be similar
- Matrices and matrix multiplication
- Solving systems of equations
- Eigenvalues and eigenvectors (the "hidden directions" in data)
- Linear transformations that stretch and rotate data
