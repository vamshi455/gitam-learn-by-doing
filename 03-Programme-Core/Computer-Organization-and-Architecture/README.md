**Category:** Programme Core &middot; **Credits:** 4 &middot; **L-T-P-S-J:** 3-1-0-0-0

## 🧠 What this subject is about
This subject opens up the computer and shows you what is inside. You learn how the "brain" (the CPU) reads instructions, how memory stores numbers, and how everything works together at lightning speed. It is like learning how a car engine works instead of just driving.

## 🌍 Why it matters in the real world
Understanding the machine helps you write faster code and choose the right hardware. Game studios, chip makers, and AI companies all care deeply about speed, and a lot of speed comes from clever use of cache and pipelining. When you train big AI models, knowing how memory and processors work saves hours of waiting.

## 🎯 A practical real-world problem to learn it
Let's build a tiny "pretend computer" on paper and in code, called a simple CPU simulator. Your make-believe machine understands just a handful of instructions, like "load a number", "add two numbers", and "store the result". You will write a small program in this baby assembly language, maybe to add up your weekly pocket money, and then make your simulator run it step by step. Watching each instruction move through the CPU shows you exactly how real computers think. Once it works, you can add a small cache and see how it speeds things up.

## 🛠️ What you'd build or try
- Design a small instruction set with commands like LOAD, ADD, and STORE
- Write a short assembly program to add a list of numbers
- Build a simulator that reads and runs your instructions one by one
- Add a tiny cache and measure how many times it avoids slow memory reads

## 📚 Key ideas you'll practice
- CPU and its components
- Memory hierarchy
- Instruction sets and assembly
- Pipelining
- Cache memory
