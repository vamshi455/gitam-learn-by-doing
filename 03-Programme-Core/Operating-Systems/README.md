# Operating Systems (24CSEN2011)

**Category:** Programme Core &middot; **Credits:** 4 &middot; **L-T-P-S-J:** 3-0-2-0-0

## 🧠 What this subject is about
An operating system, like Windows, macOS, or Android, is the boss of your computer. It decides which program runs, how much memory each one gets, and how files are saved. This subject teaches you how that boss makes fair and fast decisions behind the scenes.

## 🌍 Why it matters in the real world
Every device you own runs an operating system, and understanding it helps you write software that does not crash or slow down. Data centres that train huge AI models run thousands of programs at once, and the OS keeps them from fighting over resources. Knowing this makes you a stronger engineer at companies like Google, Microsoft, and Apple.

## 🎯 A practical real-world problem to learn it
Imagine you are the manager of a busy ice cream shop with only two servers but many customers. Who gets served first? The one who arrived earliest, or the one with the smallest order? This is exactly what an OS "scheduler" decides for programs. Let's build a simple job scheduler simulator. You give it a list of tasks, each with an arrival time and how long it takes, and your program decides the order using different rules. Then you measure which rule makes customers wait the least. You will feel like the brain of a computer.

## 🛠️ What you'd build or try
- Create a list of "jobs" each with an arrival time and a run time
- Simulate First-Come-First-Served scheduling and measure waiting time
- Try Shortest-Job-First and compare which is fairer or faster
- Add two "servers" (threads) and handle the classic deadlock where both wait forever

## 📚 Key ideas you'll practice
- Processes and threads
- CPU scheduling
- Memory management
- File systems
- Concurrency and deadlocks
