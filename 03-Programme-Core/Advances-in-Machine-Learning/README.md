**Category:** Programme Core &middot; **Credits:** 4 &middot; **L-T-P-S-J:** 3-0-2-0-0

## 🧠 What this subject is about
This subject takes the machine learning you already know and pushes it to the cutting edge. You learn the powerful modern tricks that make today's best AI so smart, like combining many models or using "transformers". Think of it as going from riding a bike to driving a race car.

## 🌍 Why it matters in the real world
The most advanced tools today, from AI image generators to chat assistants and game-playing champions, use these modern techniques. Transformers power large language models, and reinforcement learning teaches robots and game bots to improve by trial and error. Knowing these keeps you at the front of the fast-moving AI world.

## 🎯 A practical real-world problem to learn it
Let's build a program that learns to play a simple game all by itself, like balancing a pole or escaping a tiny grid, using reinforcement learning. Nobody tells the computer the rules of winning. Instead, it tries actions, gets rewards for good moves and penalties for bad ones, and slowly figures out a winning strategy, just like you learn a video game by playing. As a second challenge, you can combine several small models into one stronger team, called an ensemble, and see how the group beats any single model. These are the exact ideas driving modern AI breakthroughs.

## 🛠️ What you'd build or try
- Set up a simple game environment for an agent to explore
- Use reinforcement learning so the agent learns from rewards and penalties
- Combine several models into an ensemble and compare the results
- Experiment with a small transformer or generative model on text or images

## 📚 Key ideas you'll practice
- Ensemble methods
- Transformers
- Reinforcement learning
- Generative models
- Other modern techniques
