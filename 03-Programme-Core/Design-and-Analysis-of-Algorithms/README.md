# Design and Analysis of Algorithms (24CSEN3002)

**Category:** Programme Core &middot; **Credits:** 4 &middot; **L-T-P-S-J:** 3-0-2-0-0

## 🧠 What this subject is about
An algorithm is just a step-by-step recipe to solve a problem. This subject teaches you how to design clever recipes and how to measure whether one is faster than another. You learn to think, "Is there a smarter way to do this?"

## 🌍 Why it matters in the real world
Good algorithms are why Google can search the whole web in a blink and why GPS finds the shortest route so fast. In AI, smart algorithms decide how quickly a model learns from data. Tech companies love engineers who can turn a slow solution into a fast one, and interviews often test exactly this skill.

## 🎯 A practical real-world problem to learn it
Imagine you are planning a road trip across several cities to visit your cousins, and you want to spend the least money on fuel. Which route is shortest? Checking every possible path by hand would take forever. Let's build a "shortest route finder" that takes a map of cities and distances and finds the cheapest path. First you try the slow "check everything" way and time it. Then you use a smarter greedy or dynamic programming method and watch it run much faster. Comparing the two teaches you why algorithm design truly matters.

## 🛠️ What you'd build or try
- Represent cities and roads as a graph with distances
- Solve it the brute-force way first and count the steps it takes
- Apply a greedy shortest-path idea like Dijkstra's algorithm
- Measure and compare the running time using Big-O thinking

## 📚 Key ideas you'll practice
- Complexity and Big-O notation
- Divide and conquer
- Greedy algorithms
- Dynamic programming
- Graph algorithms
