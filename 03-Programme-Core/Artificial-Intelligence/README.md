# Artificial Intelligence (24CSEN2151)

**Category:** Programme Core &middot; **Credits:** 4 &middot; **L-T-P-S-J:** 3-0-2-0-0

## 🧠 What this subject is about
Artificial Intelligence, or AI, is about making computers do smart things that usually need human thinking, like solving puzzles or playing games. This subject teaches you how a computer can search for answers, make plans, and make good choices. It is the foundation of every "smart" system you hear about.

## 🌍 Why it matters in the real world
AI powers self-driving cars, game opponents, chess engines, and virtual assistants. The search and planning ideas you learn here are the roots that grew into today's powerful AI. Understanding them helps you see how machines actually "decide" instead of treating AI like magic.

## 🎯 A practical real-world problem to learn it
Let's build a program that solves a maze all by itself, the way a robot vacuum finds its way around your home. You give the computer a grid with walls, a start point, and a goal. The computer does not know the path, so it must search, trying directions, backing up from dead ends, and remembering where it has been. First you try a simple search that checks everywhere, then you add a "heuristic", a smart hint that points toward the goal, so it finds the exit much faster. Watching your program escape the maze feels like giving a computer a tiny brain.

## 🛠️ What you'd build or try
- Create a grid maze with walls, a start, and a goal
- Solve it with Breadth-First Search that explores step by step
- Add the A-star algorithm using a heuristic to reach the goal faster
- Turn it into a small game where the computer plays against you

## 📚 Key ideas you'll practice
- Search algorithms
- Heuristics
- Knowledge representation
- Planning
- Game playing and intelligent agents
