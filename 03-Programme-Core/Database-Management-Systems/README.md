# Database Management Systems (24CSEN2031)

**Category:** Programme Core &middot; **Credits:** 4 &middot; **L-T-P-S-J:** 3-0-2-0-0

## 🧠 What this subject is about
A database is an organised place to store lots of information so you can find it later without any mess. This subject teaches you how to design these neat storage systems and how to ask them questions using a language called SQL. Think of it as building a super-smart digital notebook.

## 🌍 Why it matters in the real world
Every app that remembers things uses a database: Instagram stores your photos, your school stores your grades, and banks store your balance. AI and ML projects also live on databases, because you need clean, organised data before a model can learn from it. SQL is one of the most requested skills in tech jobs today.

## 🎯 A practical real-world problem to learn it
Let's build a "Library Manager" for your school library. The library has books, students, and borrow records. You need to store which student borrowed which book and when it is due back. First you draw a picture (an ER diagram) showing how books, students, and loans connect. Then you create tables and use SQL to answer real questions like "Who has overdue books?" or "Which book is most popular?" You will also make sure the same information is not stored twice, which is called normalization. This is a real system every library actually needs.

## 🛠️ What you'd build or try
- Draw an ER diagram linking students, books, and borrow records
- Create tables and fill them with sample data
- Write SQL queries to find overdue books and popular titles
- Normalize your tables so no data is repeated by mistake

## 📚 Key ideas you'll practice
- Relational model
- SQL queries
- ER diagrams
- Normalization
- Transactions and indexing
