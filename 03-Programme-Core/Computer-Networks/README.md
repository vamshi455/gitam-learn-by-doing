# Computer Networks (24CSEN2041)

**Category:** Programme Core &middot; **Credits:** 4 &middot; **L-T-P-S-J:** 3-0-2-0-0

## 🧠 What this subject is about
A computer network is how devices talk to each other, like phones passing notes across the whole world. This subject teaches you how your message travels from your laptop, through many machines, and reaches a friend far away. You learn the rules, called protocols, that make this magic reliable.

## 🌍 Why it matters in the real world
The internet, video calls, online games, and cloud AI all depend on networks. When you use a chatbot online, your words travel across networks to a big server and back in seconds. Companies need engineers who understand how data moves so apps stay fast and secure.

## 🎯 A practical real-world problem to learn it
Let's build a simple "Chat App" where two computers can send messages to each other, just like a mini WhatsApp. One program will be the "server" that waits for messages, and the other will be the "client" that sends them. You will use something called sockets, which are like telephone lines between programs. As you type "Hello!" and watch it appear on the other screen, you are seeing exactly how real messaging apps work. You can then add more friends to the chat and learn how the internet handles many connections at once.

## 🛠️ What you'd build or try
- Write a server program that listens for incoming messages
- Write a client program that connects and sends text
- Send messages back and forth using TCP sockets
- Explore how the message travels through the OSI/TCP-IP layers

## 📚 Key ideas you'll practice
- OSI and TCP-IP layers
- IP addressing
- Routing
- Protocols like HTTP, TCP, and UDP
- Sockets programming
