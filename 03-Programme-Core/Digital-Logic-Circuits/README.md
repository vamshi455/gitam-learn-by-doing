# Digital Logic Circuits (24CSEN1002)

**Category:** Programme Core &middot; **Credits:** 2 &middot; **L-T-P-S-J:** 2-0-0-0-0

## 🧠 What this subject is about
Computers only understand two things: ON and OFF, which we write as 1 and 0. This subject teaches you how to combine these tiny signals using "logic gates" to make useful decisions. Think of it as learning the alphabet that every computer chip is built from.

## 🌍 Why it matters in the real world
Every phone, laptop, smartwatch, and game console has millions of these tiny logic circuits inside. Companies like Intel, NVIDIA, and Qualcomm design chips this way. Even the special AI chips (GPUs and TPUs) that train machine learning models are made of billions of these gates working together.

## 🎯 A practical real-world problem to learn it
Imagine you want to build a smart traffic light for a toy town, or a simple "vote counter" for your class. Let's pick the vote counter. Three friends each press a button to say "yes" or "no" to a plan. Your circuit should turn on a green light only when the majority (two or more) say "yes". You can't use a computer program for this, only logic gates. You will figure out which gates to wire together so the green light glows at exactly the right time. This is a real "majority circuit" that engineers use inside bigger systems.

## 🛠️ What you'd build or try
- Draw a truth table listing every possible combination of the three yes/no votes
- Work out the boolean expression that gives "green light ON" for a majority
- Wire it up in a free online simulator like Logisim or CircuitVerse
- Extend it: add a small adder so it also shows the total number of "yes" votes

## 📚 Key ideas you'll practice
- Boolean algebra
- Logic gates (AND, OR, NOT, XOR)
- Combinational circuits
- Adders
- Flip-flops and sequential circuits
